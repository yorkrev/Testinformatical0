# Backrooms

Скачать игру: нажми на **backrooms.html**, затем на кнопку со стрелкой вниз справа (**Download raw file**).
Открой скачанный файл двойным щелчком — игра запустится в браузере (Chrome, Edge, Firefox). Интернет не нужен.

Управление: `W A S D` — ходьба, мышь — обзор, `Shift` — бег, `C` — присед, `Пробел` — прыжок,
`F` — фонарик, `Esc` — пауза, `F11` — весь экран.
